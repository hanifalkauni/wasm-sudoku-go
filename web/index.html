Informasi & Cara Bermain

Game Sudoku ini menggunakan Go WebAssembly yang berjalan langsung di browser Anda untuk membuat puzzle, mencari solusi, dan memvalidasi langkah secara instan tanpa server backend!

Shortcut Keyboard:

  • Panah / WASD: Navigasi sel
  • Angka 1 - 9: Masukkan angka / catatan
  • Backspace / Delete: Hapus angka
  • N: Toggle Mode Notes (Pensil)
  • U: Undo langkah
  • H: Minta petunjuk (Hint)
  • Spasi: Pause / Resume timer
